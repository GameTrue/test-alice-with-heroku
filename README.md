# test-alice-with-heroku

Проект **test-alice-with-heroku** был разработан в рамках учебной программы [Яндекс Лицея](https://yandexlyceum.ru/). Этот проект представляет собой веб-приложение на основе Flask, предназначенное для взаимодействия с навыком Алисы, развернутое на платформе Heroku.

## О проекте

Приложение реализует игру с угадыванием, где пользователи могут выбирать темы (города, машины или еда) и отвечать на вопросы, основываясь на предоставленных изображениях. Проект демонстрирует:
- Интеграцию Flask с Heroku.
- Работа с портами, которые задаются динамически Heroku.
- Использование Flask для обработки запросов и ответов Алисы.

### Основные функции
- **Обработка запросов Алисы**: Поддержка игровых и информационных сценариев.
- **Выбор тем**: "Города", "Машины", "Еда".
- **Сохранение состояния диалога**: Использование `sessionStorage` для хранения информации о пользователе.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GameTrue/test-alice-with-heroku.git
   ```
2. Убедитесь, что у вас установлен Python 3.7 или выше.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите Flask-приложение:
   ```bash
   python test.py
   ```
5. Для развертывания на Heroku:
   - Создайте приложение на Heroku.
   - Установите Heroku CLI и выполните команду деплоя:
     ```bash
     git push heroku master
     ```

- **Веб-фреймворк**: Flask
- **Платформа развертывания**: Heroku
